## 2. 项目结构

### 2.1 目录组织
```
web/
├── app/           # Next.js 页面和组件
├── components/    # 可复用组件
├── hooks/         # 自定义 Hooks
├── services/      # API 服务
├── utils/         # 工具函数
├── types/         # TypeScript 类型
├── styles/        # 样式文件
└── public/        # 静态资源
```

### 2.2 路由设计
- `/` - 首页
- `/apps` - 应用列表
- `/apps/[id]` - 应用详情
- `/datasets` - 数据集
- `/knowledge` - 知识库
- `/settings` - 设置
